# ynov Campus League

Flutter + Firebase campus platform for students, teachers, and admins.

## Highlights
- Role-based onboarding (student/teacher/admin)
- Real-time messaging, events, and academic updates
- Minimalist, card-driven UI with light and dark themes
- Secure Firebase rules and scalable Firestore schema

## Project Structure
```
lib/
  app/                # app entry, routing, themes
  features/           # feature modules (splash, auth, dashboards)
docs/                 # Firestore schema + rules
assets/               # images & animations
```

## Getting Started
1. Install Flutter and Firebase CLI.
2. Run `flutter pub get`.
3. Configure Firebase for iOS and Android.
4. Launch with `flutter run`.
